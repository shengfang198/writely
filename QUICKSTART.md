# Writely Quick Start

## 1. Install Node.js

Install Node.js 20.19 or newer from [nodejs.org](https://nodejs.org/).

## 2. Download the Project

```bash
git clone https://github.com/shengfang198/writely.git
cd writely
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start Writely

```bash
npm run dev
```

## 5. Open Writely

Open the URL displayed in the terminal, usually:

```text
http://localhost:5173
```

Keep the terminal open while using Writely. Press `Ctrl+C` to stop it.
